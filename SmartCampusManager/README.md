\# Smart Campus Logistics \& Resource Manager



A Java-based application for managing university assets, labs, and equipment reservations.



\## Features

\- \*\*Resource Management:\*\* Add, view, and organize campus assets by type (Lab, Equipment, Hall).

\- \*\*Reservation Engine:\*\* Prevents double-booking and handles real-time resource availability updates.

\- \*\*Data Persistence:\*\* Automatically saves and loads resource states to plain-text data files.

\- \*\*Testing Suite:\*\* Automated unit tests verifying resource toggling and booking constraints.



\## Technologies Used

\- \*\*Language:\*\* Java (JDK 17+)

\- \*\*Persistence:\*\* Java File I/O (`BufferedReader`, `BufferedWriter`)

\- \*\*Version Control:\*\* Git \& GitHub
