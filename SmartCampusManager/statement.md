\# Problem Statement: Smart Campus Logistics \& Resource Manager



\## Problem Description

Managing shared resources on a modern university campus—such as specialized AI labs, high-end multimedia projectors, and seminar halls—often suffers from scheduling conflicts, double bookings, and a lack of real-time availability tracking. 



\## Scope of the Project

This application provides a centralized system to manage campus resources, track user roles (Student, Faculty, Admin), automate resource allocation, enforce booking rules, and persist all transaction states to structured file storage.



\## Target Users

\- \*\*Students:\*\* Reserve laboratories and study rooms for academic projects.

\- \*\*Faculty:\*\* Book specialized teaching tools, equipment, and seminar halls.

\- \*\*Admins:\*\* Manage resource inventories and monitor overall utilization.



\## High-Level Features

1\. Multi-role user identification.

2\. Real-time resource availability and collision prevention.

3\. File-based data persistence across sessions.

4\. Interactive CLI user management and dynamic inventory updating.
